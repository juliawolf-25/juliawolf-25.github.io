Веб-приложение для координации волонтёрских мероприятий на территории Республики Коми: поиск пропавших в лесах, помощь ветеранам, экологические субботники, донорские акции и другие социально значимые инициативы.

 Возможности

 Для волонтёров
- Просмотр ленты, карты и календаря мероприятий
- Умный фильтр по типу, городу, дате и навыкам
- Запись на мероприятия и отмена записи
- Просмотр личного рейтинга и истории участия
- Публикация отчётов в социальных сетях

 Для организаторов
- Создание мероприятий с указанием локации на карте
- Использование текстового помощника для автозаполнения формы
- Отметка пришедших волонтёров
- Завершение мероприятия с формированием отчёта
- Публикация отчётов в VK и Одноклассники

### Для администраторов
- Модерация мероприятий (одобрение/отклонение)
- Управление пользователями
- Управление справочником населённых пунктов
